Separation of powers

No component can create, authorize, and execute a trade alone. Permission is a separate artifact, not an AI opinion.

Four proofs, one control model

The demo proves both restraint and action: the AI can decline, Lockean can reject, Lockean can authorize without executing, and the gateway can execute only after verifying exact permission.
