## Decision Funnel

The only production evaluation occurred on the first open-market iteration and
recorded this completed-session vector:

```text

trend: PASS
momentum: PASS
breakout: FAIL
VIX completed close: 15.520000
volatility: PASS
intraday status at 09:30:05 ET: UNAVAILABLE
```

The runtime returned:

```text
AUTONOMOUS CYCLE: NO_TRADE | profit_first_breakout_not_confirmed
market_preflight=BLOCKED
agent_decision=SKIPPED
SESSION ENTRY ELIGIBILITY: CLOSED
```

The breakout rule requires the latest completed SPY close to exceed the prior
20-session high. The Day 21 log records the $774.97 close and the `FAIL` result,
but it does not record the prior-20-session comparison value. The log's
`spy_close=774.97` and `spy_prior_close=774.97` fields are two names for the
same latest completed close; they are not the breakout comparison.

The initial intraday-data status is expected at the first seconds of the open,
before a completed current-session minute bar is available. It did not control
the outcome because the earlier completed-session breakout gate had already
failed. After that immutable failure was latched, no further market-production
cycle was warranted.

At each later 15-minute schedule point, the runner emitted:

```text
SESSION ENTRY GATE: BLOCKED | profit_first_breakout_not_confirmed |
immutable_completed_session_evidence
```

This explains the scorecard distinction: there were 24 scheduled opportunities
but only one production entry evaluation. The other 23 were cheap local gate
checks; none called Alpaca market-data discovery or OpenAI.

## Evidence-Required Correction

Day 21 exposed a measurement defect: a hard gate can decide the entire session,
yet the log records only `PASS` or `FAIL`, not the values and margins that made
the decision. That prevents later reviewers from distinguishing a near miss
from a materially different market and weakens historical hypothesis research.

The post-session correction now records, in the existing market-context
diagnostic:

- the exact completed-session date for SPY and VIX;
- SPY completed close;
- SPY 50- and 200-session simple moving averages;
- SPY RSI-14;
- SPY prior 20-session high;
- signed SPY breakout distance as a percentage;
- VIX completed close;
- VIX 20-session simple moving average; and
- signed VIX distance from that average as a percentage.

The market-policy calculations were factored into shared functions so the
telemetry and the actual gate use the same formulas. Missing history renders as
`NA` and existing filters continue to fail closed.

No strategy or authority parameter changed. Trend, momentum, breakout,
volatility, intraday alignment, 1.50:1 after-cost economics, exposure, loss,
take-profit, stop-loss, cooldown, entry cutoff, authorization, and execution
rules are unchanged.

**Regression result:** 374 passed, one known third-party deprecation warning,
zero regressions.
