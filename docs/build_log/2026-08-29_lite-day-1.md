## Architecture Decision — Authorization Is Not Execution Permission

An `AUTHORIZED` authority decision will not itself be sufficient to execute a trade.

Execution will require a separate proposal-bound Authorization Receipt proving the exact action Lockean approved.

The future Execution Gateway must reject:

- missing authorization;
- expired authorization;
- authorization presented for a changed proposal;
- any order-relevant field that no longer matches the approved proposal.

This preserves the separation between deciding that a proposal qualifies and granting permission for the exact approved action to reach the broker.
