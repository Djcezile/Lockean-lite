# Lockean Lite

Lockean Lite is an execution-control prototype for autonomous AI trading agents.

## Competition Thesis

AI proposes.  
Lockean proves.  
Authority decides.  
Only then may software act.

The AI does not possess broker execution authority. It may produce a structured trade proposal, but an independent deterministic Lockean Authority must decide whether that proposal is allowed to proceed.
